A **Capiva Studio** cria agentes de vendas com IA que atendem no WhatsApp 24h por dia, qualificam clientes automaticamente e só chamam o dono do negócio quando o cliente está pronto para fechar.

### O que o agente faz

- **Atende** na hora, a qualquer hora, no WhatsApp do próprio negócio
- **Qualifica** cada conversa e organiza os leads em um funil
- **Agenda** horários direto na conversa, sem link externo
- **Cobra** por link de pagamento e avisa quando o cliente pagou
- **Passa para uma pessoa** quando a conversa pede atendimento humano
